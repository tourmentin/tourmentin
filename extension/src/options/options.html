Tourmentin — version d'essai

Vous testez une version qui n'est pas encore terminée.

Le silence ne veut rien dire. Si Tourmentin ne dit rien sur une page, cela ne prouve pas que la page est sûre. Personne n'a encore mesuré combien de faux sites Tourmentin laisse passer sans réagir.

Rien ne doit changer dans vos habitudes. Vérifiez les adresses comme avant. Ne saisissez jamais un mot de passe si quelque chose vous semble étrange, que Tourmentin ait réagi ou non.

Protocole de test : ne saisissez jamais un mot de passe sur une page qui vous semble louche, même pour tester Tourmentin. Ouvrez les liens reçus par courriel depuis le navigateur plutôt que depuis votre messagerie. Notez ce que Tourmentin a dit, et ce qu'il aurait dû dire.

Tourmentin analyse les pages sur votre appareil. Rien de ce que vous consultez ou saisissez n'est envoyé sans que vous le décidiez : quand vous déclarez une page, Tourmentin vous montre exactement ce qui partirait vers tourmentin.fr (adresse, texte visible nettoyé, adresses d'images — jamais ce que vous avez saisi), et n'envoie rien avant votre confirmation. Vous pouvez désactiver tout envoi dans les paramètres (« Ne jamais envoyer »).

Pour rester à jour, Tourmentin télécharge chaque heure la liste des sites vérifiés depuis tourmentin.fr. Cette opération n'envoie aucune information sur vous ni sur les pages que vous visitez.

Comment vérifier une adresse

  1. L'adresse d'un site se lit après « https:// » et avant la barre oblique suivante : dans « https://assure.ameli.fr/connexion », c'est « assure.ameli.fr ». Ce qui vient après cette barre ne dit pas chez qui vous êtes.
  2. Ce qui compte, c'est la fin de cette adresse. « impots.gouv.fr » est le site des impôts ; « impots.gouv.fr.paiement-exemple.com » ne l'est pas : il se termine par « paiement-exemple.com ».
  3. Une lettre ou un tiret de différence, c'est un autre site : « impots-gouv.fr » n'est pas « impots.gouv.fr ».
  4. Le cadenas ne prouve rien sur le site : il dit que la connexion est chiffrée, pas que vous êtes au bon endroit.
  5. Ne suivez pas le lien d'un message : tapez vous-même l'adresse officielle, ou ouvrez un favori que vous avez créé.
  6. Dans le doute, ne saisissez rien. Appelez l'organisme avec le numéro d'un courrier officiel, et signalez le message : Signal Spam (courriel), 33700 (SMS), Cybermalveillance.

Envoi à tourmentin.fr

Quand vous déclarez une page (« Cette page est frauduleuse », « Signaler comme site officiel »), Tourmentin peut en envoyer une copie à tourmentin.fr : l'adresse (sans la partie après « ? » ou « # »), la marque évoquée, les signaux du moteur, le texte visible de la page (nettoyé des adresses e-mail, numéros de téléphone et IBAN) et les adresses de ses images. Jamais ce que vous avez saisi dans les champs.

Envoi

Avec « Ne jamais envoyer », aucune déclaration ni liaison de compte ne part vers tourmentin.fr. Le téléchargement des listes (voir « Listes signées » plus bas) ne dépend pas de ce réglage : il n'envoie rien vous concernant.

Compte tourmentin.fr

Pour lier ce navigateur à votre compte, générez un code sur tourmentin.fr/gestion/liaison, puis collez-le ici une seule fois. Le serveur vérifie votre rôle à chaque action : cette extension n'est jamais la source de vérité sur le rôle.

Pages de connexion inconnues

Sur une page avec un champ mot de passe, d'un site que Tourmentin ne connaît pas et qu'il ne juge pas suspect, un bandeau discret vous rappelle de vérifier l'adresse. Rien n'est envoyé ; la mémoire des sites déjà vus reste sur cet ordinateur.

Exporter

L'export écrit un fichier lisible sur cet ordinateur. Rien n'est envoyé par Tourmentin : relisez le fichier, puis transmettez-le vous-même si vous le souhaitez. Il contient les adresses (sans la partie après « ? » ou « # »), le niveau, le motif et la marque évoquée — ni le contenu des pages, ni rien de ce que vous avez saisi.
